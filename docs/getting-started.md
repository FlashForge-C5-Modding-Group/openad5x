# Getting started

OpenAD5X replaces FlashForge's software on the AD5X with Kalico, Moonraker, Fluidd and
GrumpyScreen, and runs the IFS through AFC. It's in public alpha: see
[Installation and safety](installation-and-safety.md) before you install.

Not sure it's for you? Read [Is OpenAD5X for you?](is-it-for-you.md) first.

If you are contributing, start with [Project layout](project-layout.md) and
[Architecture](architecture/index.md). The printer configuration lives in
`AD5X-FS/fs/usr/data/config`, while Kalico, the AD5X MCU code and the AFC modules live in
`kalico-ad5x`.

Join our Discord for support and to report problems with the alpha.
